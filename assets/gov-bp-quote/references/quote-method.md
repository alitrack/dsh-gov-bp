# 报价方法细则

## 一、定形态 → 算成本 → 反推 → 夹逼

```
① 客户选档（①文档加工 / ②系统 / ③平台+智能体）
② 自下而上算成本（每行都带口径）
③ 成本 × (1 + 毛利 30%–50%) = 报价候选
④ 与同颗粒度市场成交价区间求交集
   交集非空 → 报交集
   交集为空 → 回 ① 改形态（减项/换档），不要硬报
```

「同颗粒度」是关键词：多癌种平台的整包价不能用来给单任务建模服务定价；通用知识库平台的报价不能直接套内网条文问答系统。

## 二、人月费率（CSBMK 口径）

- 来源：中国软件行业基准数据（CSBMK），年度发布，地区 × 类别给 P50。
- 口径：1 人月 = 21.75 天；含直接人力 + 间接人力 + 间接非人力 + 合理利润；不含直接非人力成本。
- 必须写：**所引期次 + 数据截止日**（跨年沿用旧期会报低，审计可能拿当期回怼）。
- 投标阶段另乘当期「规模变更因子」（报价前查当期因子表）。
- 招聘平台月薪：只能用于成本结构交叉验证，**不可与人月费率相加或替代**。

参考量级（历史期次，仅供理解结构，报价前必须换当期数据）：
A 类城市（北京/上海/深圳）约 3.1–3.2 万元/人月；B 类（杭州/南京/苏州）约 2.7–2.9 万元/人月。

## 三、文档数字化单价（按口径分档，不要混报）

| 档 | 内容 | 量级（公开中标价锚点） |
|---|---|---|
| ① | 纯扫描（拆装/扫描/图像处理/命名挂接） | 0.30–0.42 元/页（A4） |
| ② | 扫描 + OCR（不校对） | 独立公开单价极难核到；**不要用倍数推算冒充** |
| ③ | 扫描 + OCR + 校对/著录 | 0.40–0.60 元（含按条著录时另计） |
| 工程图纸 | A3/A2 以上大幅面 | 1.2–6 元/页 |

- 政采一律按页/画幅计价，「元/册」基本核不到。
- 密排印刷品（标准规范类，含表格公式）废品率更高，报价宜上浮——但要在报告里注明这是推断。

## 四、token / 模型成本怎么估（把假设写进报告）

```
页数 = 份数 × 每份平均页数
字符 = 页数 × 每页字符数（A4 密排中文含表格 ≈ 700 字/页）
token = 字符 × 0.7            ← 中文经验值：1 汉字 ≈ 0.7 token
分块重叠系数 × 1.10
```

量级参考（用于判断「模型侧不是大头」）：
- 一次性向量化：数千万字语料通常在**几十元**级；
- 单次问答（rerank + 生成）：**几分钱**级；
- 月度推理：百次级/天 ≈ 百元级/月；
- 而文档数字化 4 万页 ≈ **1.2–1.7 万元**（一次性）。

结论句必须写：**成本大头在「纸 → 干净文本」的人工作业与人力，不在 token。**

别漏「托管解析费」：托管知识库的高级解析按元/标准页计，量大时常常比向量化 + 一年推理费之和还大；自建解析即省，要作为方案选项写出来。

## 五、报价前必答四问（决定 30%–50% 价差）

1. 要不要交付**源代码**？
2. 要不要 **24 个月质保**与响应承诺？
3. 甲方是否提供**有权使用**的文本/语料？
4. 走**中央**（行业最新版）还是**省级**取费口径？

四问没有答案之前，报出的任何数字都是浮的。

## 六、合同与付款

- 付款节点：签订 30% → 初验 40% → 终验 20% → 质保期满 10%。
- 甲方义务写进合同：提供可授权文本、指定业务对口人参与评测题集、提供内网与算力、明确试运行期与质保期。
- 试运行期风险条款要看：有些合同允许「扣除修复时间后累加」甚至「重新计算试运行期」——这会直接吃掉工期与人力成本。

## 七、验收判据（可抄进合同）

- 流程：初步验收（采购人主持）→ 试运行 → 最终验收（业务科室 + 外聘专家）。
- 交付物：源代码（含注释）+ 需求规格/设计说明/测试计划/测试报告/培训计划/用户手册（纸质 + 电子）。
- 问答系统指标：答案准确率 = 正确解答数 / 全部提问数；召回率 = 正确回复数 / 知识库应答题数；MRR = 标准答案位置倒数；另有答案满意率。
- 测试题集：100 题 = 高频 60 + 同义 20 + 错误式 10 + 省略式 5 + 英文 5（分布随材料提交，可复核）。

## 八、两条红线

1. **涉密不入库**：涉密图纸/测绘成果的数字化与检索属涉密集成业务，须持资质并在物理隔离环境实施；无资质不承接，方案里不写「可处理涉密数据」。
2. **不拿无授权文本建对外服务知识库**：GB/T、行业标准、出版物均受著作权保护；官方免费渠道明确「仅供个人学习研究，未经授权禁止复制、发行、汇编、翻译或网络传播」。默认形态：条款级摘要 + 标准号索引 + 原文链接；或甲方书面担责。

## 九、未核到纪律（写进报告的必填章）

- 查不到写「未核到」，禁止用档位常识编数（云主机目录价抓不到时编「200–400 元/月」是踩过的坑）。
- 聚合站打码不等于不存在：换通道再捞；仍拿不到就留白，并放进存疑清单。
- 项目锚点按口径分层、不跨级混用：成交价 ＞ 预算/最高限价 ＞ 概算 ＞ 聚合转述 ＞ 自媒体。
- 自媒体榜单里的漂亮数字，回溯不到一手公告就不许进报价单。
