# 报价：先把「交付形态」定下来，再谈钱

客户买的不是工作量，是**交付形态**。同一套东西，报价可以是 6 万也可以是 160 万，差别只在：交不交源代码、质保几年、有没有系统、含不含智能体与集成。

所以顺序永远是：**定形态 → 算成本 → 反推毛利 → 用市场锚点夹逼**。

## 一、三档交付形态（先让客户选档）

| 档 | 交付形态 | 计价口径 | 相对量级 |
|---|---|---|---|
| ① | 文档加工与治理：整理 / 去重 / OCR / 结构化 / 元数据 / 入库（**不含新系统**） | 页数 × 单价 + 结构化人月 | 基准 |
| ② | 知识库系统（多数项目的主推档）：解析流水线 + 检索问答（答案定位到条文号+页码）+ 权限 + 增量更新 + 评测集 + 验收材料 + **源代码** | 人月为主 + 首年运维打包 | ① 的 3–6 倍 |
| ③ | 平台 + 智能体：② + 知识图谱/规则库 + 智能体 + 业务系统集成 | 人月 + 集成工作量 | ② 的 2–4 倍 |

**谈价时把议题从「多少钱」抬到这四个问题上**：要不要源代码 / 要不要 24 个月质保 / 甲方提不提供可授权文本 / 走中央还是省级取费口径。这四问答完，价差 30%–50% 自然解释清楚。

## 二、自下而上验算（金额必须有根）

```
成本 = 文档加工（页数 × 单价）
     + 知识结构化（人月 × 开发费率）
     + 系统开发（人月 × 开发费率）
     + 评测调优（人月，含评测题集编制）
     + 部署培训与验收材料（人月）
     + 首年运维（0.1–0.2 人年 × 运维费率）
     [+ 算力硬件（单列，见下）]

报价 = 成本 × (1 + 毛利)      ← 软件项目毛利按 30%–50% 反推
再与市场同类成交价区间夹逼，取交集；交集为空就回去改形态，不要硬报
```

**必须写进报告的一句话**：钱花在哪。实践中的比例是——一次性文档作业费常是「模型 + 存储月费」的 20–60 倍。**成本大头在「纸 → 干净文本」的人工作业和人力，不在 token。**

### 人月费率口径（唯一普遍被审计认可的口径）

- 用中国软件行业基准数据（CSBMK，北京软件造价评估技术创新联盟年度发布）的**地区 P50**；
- 口径：1 人月 = 21.75 天，含直接人力 + 间接人力 + 间接非人力 + 合理利润，**不含直接非人力成本**；
- 必须写明**所引期次 + 数据截止日**（跨年沿用旧期会把价报低，审计也可能拿当期数据回怼）；
- 投标阶段还要乘当期「规模变更因子」，报价前查当期因子表；
- **招聘平台月薪不能替代人月费率**（前者不含间接成本与利润），只能用于成本结构交叉验证。

### 硬件必须单列

含硬件的方案里硬件常占 70%–88%。混进软件报价会吃掉毛利，也无法单独计税。报价单里单列「算力硬件（可选）」。

### 报价单拆项（8 行，可直接抄）

| 序号 | 项目 | 口径 |
|---|---|---|
| 1 | 文档数字化与整理 | 页 × 单价 |
| 2 | 知识结构化与入库 | 人月 × 开发费率 |
| 3 | 系统开发 | 人月 |
| 4 | 评测与调优（含评测题集） | 人月 |
| 5 | 部署、培训与验收材料 | 人月 |
| 6 | 算力硬件（可选，单列） | 套 |
| 7 | 首年运维 | 年 |
| 8 | 次年及以后运维 | 年 |

**付款节点**：签订 30% → 初验 40% → 终验 20% → 质保期满 10%。

### 年度维护费怎么报

公告级的「运维 = 建设费 X%」条款通常核不到，不要用百分比当唯一依据：先按「0.1–0.2 人年 × 运维费率」反推，再对齐「建设费的 10%–20%」自检；或把首年运维打包进建设价（行业常见）。

## 三、甲方义务写进合同（不是客套，是成本边界）

① 提供其**有权使用**的语料/文本；② 指定业务对口人参与评测题集编制；③ 提供内网环境与算力（若不含硬件）；④ 明确试运行期长度与质保期。

## 四、低价档禁区

- 不要报「5 万以下的系统」：这个价位段的对标物是开源自建或 SaaS 挂牌价，客户会拿它们比。被对标时把议题抬回「源代码 + 验收指标 + 质保 + 合规责任切分」。
- 承接门槛先自检：法人主体 + 政采资格；金额档位越高，越常要求近三年同类业绩（合同扫描件 + 发票）、ISO 27001 / CMMI、审计报表。**报价前必查**：同业业绩要求 / 资质 / 源代码移交条款 / 质保期长度。

## 五、两条红线（越界即不能接）

1. **涉密数据不入库**。涉密图纸、测绘成果的数字化与检索属于涉密集成业务，须持相应资质，且在物理隔离、禁连互联网的环境实施。无资质不得承接，也不要在方案里写「可以处理涉密数据」。
2. **不承诺用无授权文本建对外服务的知识库**。推荐性国标（GB/T）、行业标准、出版社出版物均受著作权保护；官方免费下载渠道（如国家标准全文公开系统）明确声明「仅供个人学习研究，未经授权禁止复制、发行、汇编、翻译或网络传播」——**下载 ≠ 授权入库**。默认形态：条款级摘要 + 标准号索引 + 原文链接；或由甲方书面声明其有权使用。

## 六、未核到纪律

- 价格给区间必须说明来源与口径（限价还是成交价、含不含著录、税前还是全成本）。
- 查不到就写「未核到」，**不要用档位常识编一个数**（这条踩过坑：云主机目录价抓不到时编「200–400 元/月」当报价依据）。
- 聚合站打码（`******`）不等于不存在：换一个聚合站或换一条通道再捞一遍；仍拿不到就写未核到，并把它放进存疑清单。
- 项目级锚点按口径分层引用、不跨级混用：成交价 ＞ 预算/最高限价 ＞ 概算 ＞ 聚合站转述 ＞ 自媒体。把限价当成交价会把报价报高。

## 输出骨架

```
① 一句话结论：成本大头在 ______（点名，不许写「综合评估」）
② 交付形态建议：① / ② / ③ 档，理由
③ 自下而上验算表（每行给口径与人月）
④ 市场锚点对照（同颗粒度成交案例；找不到就写未核到）
⑤ 报价区间 + 毛利反推 + 与锚点夹逼的交集
⑥ 甲方义务与合同条款建议（付款节点 / 质保 / 源代码 / 验收判据）
⑦ 承接边界：能接 / 需先拿资质 / 不接（涉密与版权两条红线）
⑧ 未核到清单（逐条留白，禁止编造）
```

方法细节、锚点表与验算脚本说明见 `references/quote-method.md`。
