# 评审判据卡（七问展开）

每张卡：判据 → 追问 → 常见糊弄 → 通过长什么样。

## 一、市场失灵点

- **追问**：这件事如果完全交给市场，哪一步会断？断了谁受损？
- **糊弄**：「市场规模千亿」「需求旺盛」——这是商业判断，不是失灵论证。
- **通过**：能指出具体环节（数据在政府手里 / 需跨部门背书 / 需制度通道 / 外部性无法内部化），并说明不做会怎样。

## 二、政策依据

- **追问**：哪一份文件的哪一条？什么时间生效？现在还适用吗？
- **糊弄**：「国家高度重视」「政策大力支持」；或引用文件名但年份错（最伤专业度）。
- **通过**：文号 + 条款位置 + 施行日期，且一手核过；核不到的写「未核到」。

## 三、政策诉求

- **追问**：你要哪三件事？找哪个部门？什么时候要？给了之后你承担什么？
- **糊弄**：「希望给予政策支持」。
- **通过**：编号清单，每条带对接部门与时间窗口，按「政策能给、市场给不了」排序。

## 四、不可替代性

- **追问**：把你们换成任何一家合格供应商，方案会差在哪？
- **糊弄**：团队履历堆砌。
- **通过**：具体位（独立第三方 / 资质编号 / 已跑通链路 / 数据与渠道），并主动承认短板。

## 五、自我设限

- **追问**：你们明确不做什么？什么条件下停？谁按停？
- **糊弄**：「风险可控，将加强管理」。
- **通过**：6–8 条编号红线 + 停止条件 + 熔断责任方 + 制度未落地不承诺。

## 六、钱怎么算

- **追问**：成本大头在哪？人月怎么来的？含不含硬件与质保？
- **糊弄**：只给总价；或人月数没有依据。
- **通过**：自下而上验算 + 口径声明（含税否 / 硬件 / 质保期）+ 明确指出大头。

## 七、试点收口

- **追问**：什么指标算成功？不达标怎么办？谁来验收？
- **糊弄**：「满足甲方要求」「运行良好」。
- **通过**：阶段关卡（不达标即停）+ 可测指标（准确率/覆盖率/时效）+ 验收流程与交付物清单。

# 常见翻车（按出现频率）

1. 政策文号年份/机关错，或引用了不存在的版本。
2. 全文同一指标两个数（总数 vs 子集、人 vs 人次）。
3. 风险章节缺失，或风险全写成外部环境。
4. 技术架构没有监管接口层。
5. 政策诉求藏在正文，评审找不到。
6. 竞品名出现在正文。
7. 承诺指标没有评测集支撑。
8. 材料是「产品介绍 + 求支持」，没有失灵论证。
