# 政务 BP 评审七问

给**制定政策 / 审批试点**的政府部门看的材料，和给投资人看的路演是两套文体。评审时不要问「这个故事讲得好不好」，只问七件事，每件事要么有硬证据，要么就是缺口。

## 用法

1. 先把材料按七问逐条判：每条给 **0 / 1 / 2** 分，写下判据里缺的那一句。
2. 合计 **≥10 分**才进入修改，**<10 分**不要润色——是地基没打，重写比改快。
3. 七问全部有分之后，再跑「致命伤清单」：致命伤命中任一条，无论总分多少都不发。

## 七问（每问 2 分）

### 一、为什么要政府做（市场失灵点）

- **2 分**：能指出一个「市场自己解决不了」的具体环节（数据源在政府手里、需要跨部门背书、需要制度通道、外部性无法内部化），并说清这个环节不做会怎样。
- **1 分**：只说了「市场很大 / 需求旺盛」，没指出必须由政府介入的那一环。
- **0 分**：通篇是「我们做了一个产品，希望获得支持」。

判据句式：`这件事如果不给政策通道/数据授权，商业主体做不到，因为 ______。`

### 二、政策依据是哪一条（文号 + 条款 + 时效）

- **2 分**：每个关键论断后面挂着**可核的文号与条款**（如「中发〔2022〕46 号」「水总〔2024〕323 号」「国数综政策〔2026〕35 号」），并注明施行/有效期。
- **1 分**：有文件名但没有文号，或有文号但没条款位置。
- **0 分**：只有「国家高度重视」「政策大力支持」这类无指向表述。

红线：**文号必须一手核过**。版本号想当然是最常见的翻车点（例：水利概估算编制规定**不存在 2020 版**，是 2014 版→2025 年版）。核不到就写「未核到」，不要补一个像真的。

### 三、你要什么（政策诉求）

- **2 分**：诉求清单**编号、分条、每条注明对接部门与时间窗口**，且按「政策能给、市场给不了」排序；每条都说清「给了之后我承担什么」。
- **1 分**：有诉求但是愿望式（「希望给予支持」），没有对接部门。
- **0 分**：诉求藏在正文里，或等价于「给钱」。

### 四、为什么是你（不可替代性）

- **2 分**：给出别人难以复制的具体位（独立第三方位 / 已有的资质与业绩 / 已跑通的技术链路 / 已掌握的数据与渠道），并承认自己的短板。
- **1 分**：只有团队介绍，没有和这件事的直接咬合。
- **0 分**：任何人换上去都一样，材料里没有任何「非你不可」的证据。

### 五、风险你承认什么（自我设限）

- **2 分**：有独立的「自我设限 / 红线」章节，条目具体可执行（不做什么、什么情况下停、谁来熔断），并明示制度未落地环节以国家制度演进为前提。
- **1 分**：有风险段，但写的是「存在一定风险，我们将加强管理」。
- **0 分**：通篇零风险，或把风险写成竞品威胁。

政府对**看得见的克制**最敏感：主动写清不做边界，比多写十页优势有效。

### 六、钱怎么算（口径与量级）

- **2 分**：给出自下而上的验算（人月 × 费率 + 单价 × 数量），口径写清（含税否、含不含硬件、质保期几年），并指出**成本大头在哪**。
- **1 分**：只有一个总价，或只有百分比拆分。
- **0 分**：金额没有来源，或明显按「感觉」报。

人月费率口径用中国软件行业基准数据（CSBMK）的 P50（1 人月 = 21.75 天，含直接人力 + 间接人力 + 间接非人力 + 合理利润），**不要用招聘月薪代替**（招聘月薪不含间接成本与利润）。

### 七、试点怎么收口（阶段与验收）

- **2 分**：阶段划分明确，**每阶段带硬性关卡（不达标即停）**，验收判据是可测指标（准确率 / 召回率 / 时延 / 覆盖率），并写清验收流程（初验 → 试运行 → 终验）与交付物清单。
- **1 分**：有阶段但没有停止条件，验收写「满足甲方要求」。
- **0 分**：没有收口设计，等于无限期试点。

## 致命伤清单（命中即不发）

1. **政策依据编造或版本错**：文号、年份、发布机关任一处对不上。
2. **数据口径打架**：同一指标全文两个数（总数 vs 子集、人 vs 人次混用）。
3. **把竞品名当参照写进正文**（政府材料里出现商业竞品名 = 立场问题）。
4. **承诺了做不到的指标**（如「准确率 99%」而无评测集支撑）。
5. **涉密/资质红线越界**：写「可以处理涉密数据」却无涉密集成资质；把测绘成果、涉密图纸放进联网方案。
6. **版权红线越界**：把受著作权保护的推荐性标准（GB/T、行业标准）全文入库对外服务，却没有任何授权说明。
7. **诉求与价值错配**：要的是钱，写的是情怀；或要的是数据授权，却通篇讲技术先进。
8. **自我设限章节缺失**，且把风险全部外推给「政策环境」。
