# 申报话语 ≠ 路演话语

同一份事实，给投资人和给政府部门要用两套语言。用错不是「风格问题」，是**评审读不懂你要什么**，直接出局。

## 一、总对照表

| 维度 | 投资人 BP（错用于政府） | 政务 BP（正确） |
|---|---|---|
| 讲什么回报 | ROI、估值、退出路径 | 政府价值：改革样本 / 治理抓手 / 惠民增收 / 税源本地化 |
| 数据的用途 | 证明市场够大、能赚钱 | 证明「窗口已开、空白存在」 |
| 竞争 | 对比竞品、抢份额 | 对比**先行地区的验证点**，空白点即定位 |
| 收尾 | 融资金额与股权 | 政策诉求清单：要什么、找谁、为什么是你 |
| 风险 | 弱化或后置 | **自我设限前置**：不做边界 + 停止条件 |
| 时间观 | 三年做到多大 | 分阶段可收口，每阶段独立价值 |
| 免责 | 律师话术 | 明示「制度未落地环节以国家制度演进为前提」 |

## 二、逐句改写示例

| 路演句 | 改成 |
|---|---|
| 「这是一个千亿级市场」 | 「该领域现有主体 N 家，覆盖 A 类场景；B 类场景（列出）尚无合规通道——空白在这里」 |
| 「我们的技术领先行业 2 年」 | 「本方案已跑通 X 链路（附实测口径），在 Y 环节比现行人工流程减少 Z 步」 |
| 「本轮融资 3000 万，出让 15%」 | 「请求三项支持：① 数据源接入授权（对接：数据局）② 试点场景背书（对接：行业主管）③ 制度通道（对接：网信/法制）——我方对应承担 A/B/C」 |
| 「竞争优势是团队来自大厂」 | 「不可替代位：独立第三方身份 + 已具备的资质/业绩（列编号）+ 已跑通的技术链路」 |
| 「风险可控」 | 「八条自我设限：不做什么、什么条件下停、谁熔断（逐条编号）」 |
| 「预计三年营收 X 亿」 | 「试点期 12 个月，关卡：准确率 ≥__、覆盖 __ 家、投诉率 ≤__；不达标即停」 |

## 三、三种叙事地基（换地基 = 全文重写）

1. **平台底座版**：借成熟平台的数据与能力证明模式可行。
   - 适用：已有可引用的平台公开数据。
   - 必答：「平台这么成熟，为什么还需要你们？」→ 答「平台做通用能力，本方案做本地合规落地与第三方治理位」。
2. **从零成长版**：从零培育本土主体。
   - 适用：本地无主体、需要政策雪中送炭。
   - 必答：「为什么扶持从零主体？」→ 论证独立第三方（征信/公证式）是制度空白，通用平台不愿承担属地责任。
3. **全行业版**：把单场景升维为基础设施。
   - 适用：已有单点验证，要拿更大范围支持。
   - 必答：「价值回流」——数据不能只流出，要给出回流三通道 + 一本账，否则政府判定为「拿走数据」。

换版时最容易漏的是：**上一版的证据在新地基里不再成立**。换版必须重跑一遍数字口径与政策依据。

## 四、数字口径纪律

1. **同一指标全文只能有一个数**：总数 vs 子集、人 vs 人次、覆盖机构数 vs 覆盖人口，全部写清口径。
2. **只用公开口径**：财报、部委发布、试点宣传稿、官方统计年鉴。找不到公开口径的量，不要写具体数字，写「未核到」或给区间并注明推断。
3. **规模数字查官方发布页**：不要用二手汇总（同一数据集常有三个不同口径在流传）。
4. **交付前机械核一遍**：

```bash
# 抽出所有数字，按单位分组，检查同一单位是否出现量级差 1000 倍以上（多为两种口径）
grep -o '[0-9][0-9,\.]*\s*\(万\|亿\|%\|人\|人次\|个\|家\|元\)' draft.md | sort | uniq -c | sort -rn | head -40
```

命中量级差就回原文核：是「3 人」和「30000 人」并存（口径不同），还是「1,234」与「1234」两种写法（统一写法）。

## 五、禁词与立场检查

```bash
# 商业竞品名：政务材料正文必须 0 次
grep -n -i '竞品A\|竞品B\|boss\|zhipin\|freelancer' out.html
# 无指向表述
grep -n '高度重视\|大力支持\|政策利好\|风口' out.html
# 路演词残留
grep -n '估值\|退出\|份额\|GMV\|获客成本\|融资' out.html
```

- 用户给的**公开口径参照**（如某省政务平台的公开数据）可以保留，注明来源。
- **商业竞品名必须清零**：出现在政务材料里是立场问题，不是文风问题。
- 「我们与某平台无隶属关系」这类声明放页脚，不占正文。

## 六、写给谁看（决定详略）

| 读者 | 关心 | 材料侧重 |
|---|---|---|
| 业务处室 | 能不能解决我的考核指标 | 问题与场景、验收判据 |
| 信息化/数据部门 | 数据从哪来、怎么管、会不会出事 | 机制、分级管控、监管接口 |
| 发改/财政 | 钱怎么算、能不能复制 | 取费依据、分阶段投入、样本价值 |
| 领导 | 风险与政治站位 | 政策依据、自我设限、试点收口 |

一份材料要能同时被四种人翻到自己的那一页——这就是九章顺序存在的理由。
